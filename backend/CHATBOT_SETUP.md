# GovBridge AI features (Gemini or local fallback)

GovBridge uses Google's Gemini API model `gemini-3.7-flash` for the chatbot, startup challenge recommendations, and the Government problem builder only when `GEMINI_API_KEY` is configured. Recommendations send the startup profile fields and public challenge descriptions to Gemini; the profile is saved in this browser. Generated challenge drafts require officer review before publishing. The chatbot does not access the app database or save conversations. The API key stays on the backend and is not sent to frontend code.

When Gemini is not configured or is unavailable, the chatbot uses its offline FAQ, challenge recommendations use keyword matching, and the problem builder uses local templates. No AI makes final eligibility or proposal evaluation decisions.

## Start without an API key

1. Open a VS Code terminal.
2. Run:

   ```powershell
   Set-Location "E:\SIH main\GovBridge\backend"
   .\venv\Scripts\python.exe chatbot_api.py
   ```

3. Leave the terminal open and use the site. The health address is `http://127.0.0.1:5001/api/chat/health`; it should show `"mode":"free_offline_faq"`.

## Optional: enable Gemini Free Tier

1. Open [Google AI Studio API keys](https://aistudio.google.com/apikey) and sign in.
2. Create or select a project that shows **Free**. Do not set up billing or add a payment method. Google says new users start on Free Tier, but model access and request limits can vary.
3. Create an API key and copy it. Keep it private; never put it in frontend files or send it in chat.
4. In Windows, search for **Edit environment variables for your account**. Under **User variables**, choose **New** and set:
   - Variable name: `GEMINI_API_KEY`
   - Variable value: paste the key
5. Click **OK** on the dialogs, then completely close and reopen VS Code and restart the chatbot backend.
6. Open `http://127.0.0.1:5001/api/chat/health`. It should show `"mode":"gemini_free_tier"`.

The same `GEMINI_API_KEY` is read by the main application backend. Restart the backend started with `python app.py` on port 5000 after setting the key. The Recommended Challenges page and Government AI-Assisted Problem Builder use Gemini through that backend; they fall back automatically if the key is missing or Gemini is unavailable.

If quota is reached or Gemini has an error, the chatbot automatically answers using the offline FAQ. The model response is generated by Gemini, so avoid sending confidential or personal information.
